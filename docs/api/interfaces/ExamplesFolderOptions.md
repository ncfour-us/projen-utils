# Interface: ExamplesFolderOptions

Options for the `ExamplesFolder` construct

## Properties

> `readonly` `optional` **examplesFolderName?**: `string`

#### Default

```ts
'examples'
```

***

### exampleTsFile?

> `readonly` `optional` **exampleTsFile?**: `boolean`

Generate a `example.ts` file in the examples folder

```ts
true
```
